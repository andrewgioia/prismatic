# Prismatic

Prismatic is a new software and game company that my brother and I are starting. We've been working in software for 15 years together and want to start cranking out software, games, and other products that we wish were available. We want to build them purposefully and with care, respecting the user completely, and with none of the common dark patterns and bad incentives that current software companies have.

This is the marketing homepage for this new company and it needs to do 3 things: tell the potential customer who we are and why we're good at what we do, showcase the products we have available, and message our brand/philosophy.

## Brand

The main qualities we want our brand to convey are those of 90s era software companies: quality software, built to serve specific tasks, with the user's quality of life as the chief priority. We love the 90s synthwave/retro vibe and want to build that into the brand imagery as well.

Our software and style should be minimal but with personality and whimsy. Things we love stylistically are fantasy card games, Dungeons and Dragons, minimalist design, old school computer hardware, Bauhaus and similar aesthetics, and primary and CMYK colors.

## Code philosophy

This website should be written in HTML and CSS only. It should use modern CSS and prefer CSS for all interaction and functionality whenever possible.

Javascript should be only used when absolutely necessary. If we do use JS, it should be vanilla and be as minimal and simple as possible.

Cross-browser support is mandatory, even if it means doing things with `@supports` declarations, though we do not need to support browser versions earlier than 2023.

When naming things, prefer single words over multiple words separated by hyphens.

Use sementic HTML elements whenever possible, and prefer them. Raw `<div>` elements should be used as a last resort.

Use `lvw`, `lvh`, and`rem` units when possible and when it makes sense. Do not use `em` units.

Prefer whole numbers and normal values, like 1 and 0.5, instead of strange numbers like 0.96 and 0.44.
